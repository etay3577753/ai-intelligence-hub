### טכניקות ותובנות מפתח
- **חשיבות CI/CD למניעת קריסות**: גם שינוי קטן בקוד יכול לגרום לקריסה ב-production, ו-CI/CD נועד למנוע זאת באמצעות תהליכים מובנים.
- **Continuous Integration (CI)**: תהליך שבו בכל דחיפת קוד מורצים אוטומטית בדיקות (unit testing, בדיקות אינטגרציה, בדיקות פורמט) לפני שהקוד מגיע ל-production.
- **Continuous Deployment (CD)**: תהליך שבו, אם כל בדיקות ה-CI עברו בהצלחה, הקוד נפרס אוטומטית ל-production ללא התערבות ידנית.
- **קלות הקמת פייפלינים כיום**: הקמת פייפלין של CI/CD הפכה קלה ונגישה, במיוחד עם כלים כמו GitHub Actions ובעזרת AI.
