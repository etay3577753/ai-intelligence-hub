## About Bolt.new
Bolt.new is an AI-powered full-stack web development tool by StackBlitz.
It can build, run, edit, and deploy full-stack web apps entirely in the browser.
Uses AI (Claude by Anthropic) to generate complete applications from prompts.

## Key Features
- Full-stack web app generation from natural language
- In-browser execution environment (no local setup)
- Supports React, Vue, Svelte, Node.js, and more
- One-click deployment to Netlify/Vercel
- Import from GitHub
- Real-time code editing alongside AI

## Pricing
- Free tier: limited AI tokens per day
- Pro: unlimited AI usage, more compute
